# 🎙️ 영어 읽기 스프린트 (Reading Sprint)

원어민 음성을 듣고 마이크로 직접 따라 읽으며 실시간 AI 발음 정확도와 스피드를 평가받는 영어 말하기/읽기 에듀테크 서비스입니다.

---

## 🌟 주요 기능 및 특징

### 1. 🎯 도전 모드 (난이도 선택)
- **🌱 일반 모드 (기본 1x 점수)**:
  - 화면에 영어 문장과 한국어 해석(보조)이 표시됩니다.
  - 🔊 **원어민 발음 듣기(TTS)** 버튼을 눌러 정확한 원어민 발음과 억양을 먼저 듣고 연습할 수 있습니다.
  - 마이크로 따라 읽어 기본 점수(최대 120점)를 획득합니다.
- **🔥 고급 모드 (해석 보고 말하기 • 점수 2배 더블 ⚡)**:
  - **영어 문장이 블라인드(가림막) 처리**되고, 오직 **한국어 해석**만 크게 화면에 제시됩니다.
  - 학생은 제시된 한국어 해석을 보고 머릿속으로 영작/영어를 떠올려 마이크에 대고 영어로 말해야 합니다.
  - 발화 전에는 원어민 듣기가 제한되며, 발화 완료(채점) 후 목표 영어 문장과 정답 원어민 발음이 공개되어 피드백을 받습니다.
  - 높은 난이도에 걸맞게 **획득 점수가 2배(더블 스코어, 문장당 최대 240점)**로 계산되어 명예의 전당 고득점 1위 등극에 도전할 수 있습니다!

### 2. 🤖 실시간 AI 발음 평가 엔진
- **Web Speech API(STT)**를 통한 음성 인식 및 레벤슈타인 편집 거리 알고리즘 기반 정밀 발음 일치도(%) 산출.
- 문장당 단어 수 기준 자연스러운 발화 속도를 평가하는 **스피드 보너스(최대 +20점)** 부여.
- 발화 완료 후 학생이 읽은 발음과 목표 영어 문장을 시각적으로 비교 분석.

### 3. 🏆 실시간 명예의 전당 & 학급 랭킹
- **실시간 Firestore 동기화**: 완주 즉시 학급 및 전체 랭킹에 무지연 반영.
- **필터링 옵션**: 기간별(전체, 이번 달, 이번 주), 단원별, 학년/반별, **난이도 모드별(전체, 일반, 고급)** 필터 제공.
- 학생 개인정보 보호를 위한 **이름 자동 마스킹(홍O동)** 표준 준수.

### 4. 👩‍🏫 교사 관리자 모드
- **24개 단원 및 문장 관리**:
  - 문장 입력 시 `영어 문장 : 한국어 해석` 형태로 입력하면 고급 모드(해석 보고 읽기)와 일반 모드가 완벽히 동시 지원됩니다.
  - 예시: `Hello, nice to meet you. : 안녕하세요, 만나서 반갑습니다.`
  - 콜론(`:`) 없이 영어 문장만 입력된 경우에도 기본 내장 번역 사전을 통해 자동 해석 매핑 지원.
- **성적표 조회 & 엑셀/CSV 다운로드**:
  - 순위, 학생 이름, 학적, 단원, **난이도(일반/고급)**, 점수, 정확도, 소요 시간, 달성 일시를 포함한 종합 리포트 제공.
- **학급 성적 일괄 삭제 및 보안 관리**: 학년/반 단위 데이터 일괄 정리 기능.

## 🚀 기술 스택
- **프론트엔드**: HTML5, Vanilla JavaScript (ES Module), Tailwind CSS
- **음성 기술**: Web Speech API (SpeechRecognition + SpeechSynthesis)
- **백엔드/데이터베이스**: Google Firebase Firestore
