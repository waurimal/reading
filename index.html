영어 읽기 고득점 꿀팁

  • • 원어민 음성 듣기: 🔊 듣기 버튼을 눌러 원어민 발음과 억양을 먼저 확인하세요.
  • • 정확한 발음: 단어 끝소리(자음)까지 명확하고 또박또박 발음할수록 높은 정확도를 얻습니다.
  • • 스피드 보너스: 망설이지 않고 자연스러운 속도로 읽으면 추가 스피드 점수가 부여됩니다.
  • • 크롬(Chrome) 브라우저 권장: 마이크 권한을 허용하여 최적의 AI 음성 인식을 경험하세요.

마이크 권한 영구 허용 설정 안내

🌐 1. 웹사이트 (HTTPS) 또는 로컬 서버 (localhost) 접속 시

1) 브라우저(Chrome/Edge) 주소창 왼쪽의 조율기(또는 자물쇠 🔒) 아이콘을 클릭합니다.
2) 마이크 항목을 '허용(Allow)'으로 변경합니다.
3) 이후에는 다시는 묻지 않고 클릭 즉시 음성인식이 시작됩니다!

📁 2. 로컬 파일 (file:///)로 직접 열었을 때

크롬 브라우저의 기본 보안 정책상 file:/// 경로에서는 마이크 권한을 영구 저장하지 못하고 매번 묻도록 설계되어 있습니다.
프로젝트 폴더의 [로컬서버_마이크영구허용_실행.bat]을 더블 클릭해 실행하시면, 1회 허용 후 영구적으로 다시 묻지 않습니다!
